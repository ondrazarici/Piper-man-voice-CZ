
# Kernel
### Český hlas pro Piper TTS

**Pozor, přichází Kernel.**

Kernel je český hlasový model vytvořený pro **Piper TTS**, navržený s jediným cílem — nabídnout český hlas, který působí co nejplynuleji, přirozeněji a příjemněji při každodenním poslechu.

Nejde jen o to, aby hlas správně přečetl text.

**Kernel má mluvit.**

Je stavěný pro souvislou řeč, běžnou konverzaci i delší hlasové výstupy. Při správném nastavení dokáže působit překvapivě plynule a přirozeně, takže posluchač po chvíli přestává vnímat samotný syntetický hlas a začíná vnímat především to, **co říká**.

### Proč právě Kernel?

- 🇨🇿 **Český hlas** – určený pro českou výslovnost a český text.
- 🗣️ **Plynulá řeč** – zaměřený na přirozené spojování slov a vět.
- 🎙️ **Příjemný pro delší poslech** – vhodný pro asistenty, automatizaci i delší mluvené výstupy.
- ⚡ **Piper TTS** – běží v prostředí Piper a je vhodný i pro lokální použití.
- 🏠 **Ideální pro domácí asistenty** – například pro hlasové asistenty, automatizaci chytré domácnosti nebo vlastní AI projekty.
- 🔊 **22,05 kHz** – model používá vzorkovací frekvenci 22 050 Hz.
- 👤 **Jeden hlas** – model je určen pro jednoho mluvčího.

### Vytvořen pro Kasandru

Kernel vznikl jako součást projektu **Kasandra**, kde má sloužit jako přirozený český hlas pro lokálního hlasového asistenta.

Ale jeho využití tím rozhodně nekončí.

Může být použit všude tam, kde potřebujete **rychlý, lokální a český hlas bez závislosti na cloudové službě**.

Od jednoduchého přečtení upozornění…

přes odpovědi domácího asistenta…

až po dlouhé souvislé dialogy.

### Kernel není jen hlas.

Je to krok směrem k tomu, aby **lokální TTS znělo jako skutečná řeč**.

A pokud hledáte český hlas pro Piper, který dokáže mluvit plynule a přirozeně, **Kernel rozhodně stojí za vyzkoušení.**

**Kernel — český hlas pro Piper.  
Méně syntézy. Více řeči.**
